## Gotchas

- No git identity in this clone: commit with `GIT_AUTHOR_*` / `GIT_COMMITTER_*` env vars
  set to `git log -1 --format='%an <%ae>'`. No `gh`: push, then give a prefilled
  `compare/main...<branch>?quick_pull=1&title=...&body=...` link.
- After `app/globals.css` token changes: stop the dev server, `rm -rf .next`, restart.
- An orphaned `next dev` from an earlier session can hold port 3000; find it with
  `netstat -ano | grep :3000` and stop it.
- The browser pane often returns stale screenshots. Verify with computed styles and DOM
  reads, and ask the user to check visuals.
- React Flow rebuilds its nodes on every graph change, so its own `selected` is dropped;
  the Spark target lives in `SparkTargetContext`.
- An absolute child of a card starts inside the card's CSS border. That bit the old SVG
  stroke; keep it in mind for any overlay on a card.
- Playwright's Chromium is installed; `npm run test:e2e` reuses a running dev server.
