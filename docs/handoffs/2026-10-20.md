## Gotchas

- The dev server keeps dying between turns: restart with the preview tool (`canvasrx-dev`),
  wait for HTTP 200, then run scripts. First compile can time out a script; rerun.
- Several files are CRLF. String replacements from shell/node scripts silently miss; use the
  Edit tool.
- The report renders `NextStepsCard` twice (one hidden for mobile). DOM work must target the
  visible one (`offsetParent !== null`).
- React Flow paints edge labels under nodes; anything that opens from a pill needs the z-index
  rule above.
- After `app/globals.css` token changes: stop the dev server, `rm -rf .next`, restart.
